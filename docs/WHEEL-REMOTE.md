# WHEEL-REMOTE.md —— 方向盘（快拆盘）上的第三块板：构想与方案

**这份文件是什么**：车主的一个**未来**构想 —— 在快拆方向盘的喇叭盖里放一块**带触摸屏的
ESP32-S3 开发板**，通过 **ESP-NOW** 与仪表那两块板联动（遥控切主题、按转速/速度触发音频等）。
**方向盘这边还没开工**（截至 2026-10-15：**快拆方向盘已经装上**，喇叭盖里的屏还没有）。
本文件只做**设计与风险清点**，不产生任何代码改动。

★ 记法：每条结论尽量带**出处**（仓库文件:行号 / 实测日志）；查不到的写"**未核实**"，不猜。

---

## 1. 为什么要它 / 它能干什么

现有两块 2.8C 的分工：**主板（右）= 速度+进气**、**从板（左）= 转速+水温**，两者之间**零根线**，
走 ESP-NOW（`LINK_PHY_UART=0`）。轮上第三块板可以承担三类事：

| 用途 | 可行性 | 说明 |
|---|---|---|
| **① 按转速/速度触发音频** | ★ 最合适 | 仪表那两块 2.8C 只有**有源蜂鸣器**（只会响/不响、不能变调 ✗），2026-10-15 已决定**把蜂鸣器整条砍掉**；要"好听的声音/语音"只能另找发声端 ⇒ **轮上那块板是天然的发声端** |
| **② 遥控切换主题** | 可行，但要设计 | 主题现在是"**写 flash 主题分区（`0x210000`）+ 重启生效**"（2026-10-15 实测），不是运行时可切 ⇒ 见 §5 两条路 |
| **③ 轮上小屏显示**（转速/档位/水温…） | 未定 | 车主还没提；但既然有屏，代码上是最简单的一项（只收广播、画个小数字） |

★ **触发源已经在手**：主板已经算出整车状态，而且 2026-10-15 把两个阈值**统一**了 ——
**转速红区 5500 rpm**、**高速红 150 km/h**（改前的 5800/6200 与 120/150 两套不一致的问题已修）。
轮上板拿这两个数当触发条件即可，不必自己解析车辆数据。

## 2. 硬件：轮上板选什么

- **必须自带音频通路**：要么是带 **ES8311 一类 codec + 功放 + 喇叭座**的板子（我们手上退掉的那块
  微雪 DualEye 就是这种），要么 **ESP32-S3 + MAX98357A（I2S 数字功放）+ 小喇叭**自己拼。
  ⇒ 能放 **WAV/语音**；纯 PWM 蜂鸣器那套（一块板一颗喇叭、只能出方波）不推荐 ✗。
- **触摸屏尺寸**：盘盖里的可视面积很有限（**未核实**具体可用直径）；建议先用小尺寸
  （1.28"/1.9" 这类）试装，而不是直接上 2.8"。
- **环境**：黑色盘盖**夏天暴晒温度很高**（LCD 常规上限约 70 ℃ ✗ ⇒ 优先宽温屏或 OLED）；
  轮上**震动**持续存在 ⇒ 连接器要防松（排线打胶/锁扣）。
- **音频峰值电流**：功放瞬时电流可达数百 mA~1 A ⇒ 轮上**就近并大电容**（≥470 µF）防掉电复位 ✓。

## 3. ★ 真正的难点：旋转体怎么取电

方向盘中心是**旋转**的，而车身线束是静止的 ⇒ 5 V 与地要跨过旋转界面。

| 方案 | 可行性 | 说明 |
|---|---|---|
| **带集电环（滑环）的快拆座** | ★ 推荐 | 市面有集成多路滑环的快拆座，可过 5 V/GND + 一根数据（本方案其实只要 2 根电） ✓ |
| 走**气囊游丝**的富余通道 | ✗ 一般没有 | 206 的游丝针脚通常没有富余；且**气囊已被拆掉**（见 §6）后那几路能不能改用途**未核实**（涉及安全件，需查电路图 + 自行担责） |
| **喇叭线取电** | ✗ 不行 | 喇叭按钮是**搭铁开关**（按下把继电器线圈接地），那根线上**没有可用电源** ✗ |
| 轮上独立电池 + 无线充 | △ 不建议 | 停车才能充；夏天高温 + 锂电池在方向盘里 ⇒ 安全与寿命都差 ✗ |

★ 结论：**取电方案 = 带滑环的快拆座**（先定这个，其余都跟着它走）。**未核实**：现有快拆座是否带滑环、
有几路、额定电流多少 —— 需要车主提供型号或照片。

## 4. 通信：ESP-NOW 加第三种角色

- **物理层不用改**：ESP-NOW 支持多节点；现在两块板已经在一个信道上（实测 `ch=6` ✓），
  轮上板离仪表 **不到 1 米** ⇒ 这是链路质量最好的一跳（延迟量级 1~5 ms ✓）。
- **现有协议**（出处：开机日志那两行）：帧种类见过 `TICK` / `DATA` / `HELLO`（约 5 s 一次）/
  `STATUS`（2 Hz）；角色由 `lib/link/link_role.h` 定（MASTER/SLAVE）。
- **要加的东西**：第三种角色（建议叫 **`REMOTE`**）+ 一帧"状态/触发"。
  字段建议（草案，实现时再定）：`v`（协议版本）/ `role` / `rpm` / `kmh` / `flags`
  （红区、高速、水温高…）/ `theme_id`（当前/目标主题）。
- ★★ **向后兼容是硬要求**：新帧/新字段**不能被两块现有固件当成坏帧**。
  **待核实**：现有解析对"未知帧类型/未知字段"是**忽略**还是会报错 —— 动手前必须先查
  `lib/link/` 的解析分支与它的 native 用例（若现在不是"未知即忽略"，就要先补这一条）。
- **速率够不够**：车速/转速走 `STATUS` 的 2 Hz（500 ms 粒度）✓ 对"过了阈值响一声"够用；
  若将来要做"换挡提示灯"那种毫秒级，就得给触发单独发**事件帧**（只在阈值穿越时发一次）✓。

## 5. 遥控切主题：两条路

主题不在固件里，而是 **flash 的主题分区 `0x210000`（16 KB，见 `partitions-s3-now.csv:17`）**，
设备**开机时读一次**（日志：`theme: 已加载 (2579 字节, bg=…, face=…)`）⇒ 所以"切主题"必须落到这上面。

| 方案 | 做法 | 代价 |
|---|---|---|
| **A. 预置多套 + 切换=重启** | 主题分区只能放一套 ✗ ⇒ 改成"把多套主题预置在**另一个分区/文件系统**里，切换时把选中的那套**拷进主题分区并重启**" | 简单、稳；切换时屏黑 **2~3 秒**（重启）✗ |
| **B. 运行时热加载** | 让 `theme_store` 支持"重读 + 应用"，各 UI 对象支持重刷 | 一次性工作量中等（要处理弧/表情/读数全部重刷），但切换**瞬时、无黑屏** ✓ |

★ 建议：**先 A 后 B**。A 能在不改渲染层的前提下先跑通"遥控切主题"这条链；
B 等真的嫌黑屏碍事再做 ✓。
★ 顺带记两个今天踩过的坑：主题文件**只有一份是权威**（板上那份 = `tools/theme-editor/local/theme-fixed.json`，
2579 B；仓库里 `tools/theme-editor/theme.json` 是**另一份**，1388 B ✗ 别混）；
写主题分区用 `esptool write_flash 0x210000`，且**必须带 `PYTHONIOENCODING=utf-8`**（否则刷写中途崩、板子变黑 ✗）。

## 6. 风险与红线（动手前必须知道）

1. ★★ **气囊**：2001 的 206 CC 方向盘中是**气囊** ⇒ 中央换成屏 = **拆掉气囊**。
   安全、年检、保险都受影响 ✗，且气囊灯需要处理（常见做法是加电阻骗过检测 ✓）。
   **这是车主自己的判断**；本文件只负责把后果写清。
2. **喇叭按钮要挪位**：原来在盘中央，现在中央是屏 ✗ ⇒ 快拆盘一般把喇叭改到**盘辐按钮**，
   改装时一并做 ✓。**喇叭必须一直可用**（年检项 + 安全件）✓。
3. **不许影响仪表两块板的现有链路**：新角色/新帧必须向后兼容（§4 ★★）；轮上板可以**随时掉线**
   （没电/死机），仪表两块板**必须照常工作** ⇒ 设计上做成"**没有轮上板也一切正常**" ✓。
4. **不碰安全件电路**：游丝/气囊线束的工作要么不动 ✗，要么由专业电工确认后动 ✓。
5. **热与电**：§2 的暴晒温度、§2 的功放峰值电流（就近大电容）✓。

## 7. 分阶段计划（不影响当前工期）

| 阶段 | 做什么 | 判据 |
|---|---|---|
| **P0** | 轮上板**单独**跑通：触摸 + 播放 WAV + 收 ESP-NOW 广播（发端先用手机/第三块板模拟） | 能自己出声、能收到广播并打串口 |
| **P1** | `lib/link/` 加 `REMOTE` 角色 + 触发帧；先只发"红区/高速"两个 flag | 仪表板照常工作（无轮上板时零影响 ✓），轮上板能收到并打日志 |
| **P2** | 遥控切主题（先走 §5 方案 A） | 轮上按一下 ⇒ 仪表主题真的换了 |
| **P3** | 装车：滑环取电、盘盖机械、喇叭挪位、气囊灯处理 | 上路实测 |

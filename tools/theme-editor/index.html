打开安装包

三种都认：assets.bin（配色 + 图片清单一起恢复）、theme.json、 image.bin。★ 与「高级 → 主题文件」里那两个按钮是同一个输入框、同一条读取路径 （这里没有第二套实现）。读入之后预览、槽位清单、各色板与底板深浅都会跟着刷新。

槽位清单（背景 + 表情）

背景要铺满 480×480（可用 JPEG）；表情必须带透明背景（PNG）—— JPEG 当表情会被拒绝。表情图拖进来/选文件会弹框选：方框内是要保留的部分， 拖动平移、滚轮（或双指）缩放，框外丢掉；确认后得到一张主体居中、 四周透明的方图。每格都能单独换图或清除。
★ 这些**技术参数都在「高级 → 图片列表」里**（在那一格上调）： 缩放方式（保持比例 / 铺满 / 拉伸）、裁透明边、目标宽度、播放顺序 —— 车主模式只负责"哪一格放哪张图"。

          image 分区固定在 0x254000(两块板偏移相同),大小按下面的「目标板」：
          经典板 1 MB / S3 两版 8 MB。

          刷这一区不动固件：换图只刷这一个分区，不用重新编译，也不用重烧 app。
        

        

          
          
        

        

          ① 端口改成你电脑上的（设备管理器里看）：2.8C（最终板）刷写与监视走板载
          UART 口 = 那个 Type-C 口（板载 CH343P，就是 COMx）；它的原生 USB
          (GPIO19/20) 只引到 12PIN 排针上，没有杜邦线时够不着。

          ② 直接 python -m esptool 在没装 esptool 的 python 上会报
          No module named esptool（或 intelhex）——
          刷之前先把三个路径挂上 PYTHONPATH，完整命令见
          tools/theme-editor/README.md 的「微雪双屏 240×240」那一节
          （含 2.8C 的对应口径）。

          ③ 成功以 esptool 最后那行 Hash of data verified. 为准。

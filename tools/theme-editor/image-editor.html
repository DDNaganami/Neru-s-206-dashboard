这里的颜色就是**主题里那四条弧 + 四处读数文字**：改完点「导出 theme.json」， 用 esptool 刷进 theme 分区就生效（固件不用重编译）。 换了底图看不见字就是在这里改：底色深就把读数改成浅色，底色浅就改成深色 —— 右边的预览会立刻跟着变，所以**预览就是这里的把关人**（颜色和底图太接近， 预览里一眼就看得出来）。
本页只写底色、四条弧、读数颜色；五官、开机时长、读数位置/字号那些字段缺失时 固件用默认值 —— 要调它们请用主题编辑器（两页共用同一份配色，不会互相覆盖）。

3 · 刷写

image 分区固定在 0x254000(两块板偏移相同),大小按上面的「目标板」： 经典板 1 MB / S3 两版 8 MB。
刷这一区不动固件：换图只刷这一个分区，不用重新编译，也不用重烧 app。
① 端口改成你电脑上的（设备管理器里看）：2.8C（最终板）刷写与监视走板载 UART 口 = 那个 Type-C 口（板载 CH343P，就是 COMx）；它的原生 USB (GPIO19/20) 只引到 12PIN 排针上，没有杜邦线时够不着。 历史档（DualEye 240 那块）反过来：走原生 USB（当时是 COM5） —— 该板已于 2026-09-22 退货，这句只作同类板参考。
② 直接 python -m esptool 在没装 esptool 的 python 上会报 No module named esptool（或 intelhex）—— 刷之前先把三个路径挂上 PYTHONPATH，完整命令见 tools/theme-editor/README.md 的「微雪双屏 240×240」那一节 （含 2.8C 的对应口径）。
③ 成功以 esptool 最后那行 Hash of data verified. 为准。
C 数组是给"想把图直接编进固件"用的；日常换图不需要。

206Dash 图片编辑器

拖图进来 → 选用途 → 导出 image.bin → 刷到 image 分区（固件不用重编译）

1 · 图片列表

把 PNG / JPG / WebP 拖到这里
（或点上面的「＋ 添加图片」）

2 · 尺寸与配色

与主题里的 bg_color 一致：图片透明度会按这个底色合成
叠一层仪表弧，看遮挡关系
左右屏各取自己那一套
开机画面不在这里：它是程序化扫表动画（淡入 → 扫表 → 睁眼），不占图片资源。

3 · 刷写

image 分区在 0x254000，大小 1024 KB。
端口改成你电脑上的（设备管理器里看，一般是 COM3～COM7）。
C 数组是给"想把图直接编进固件"用的；日常换图不需要。

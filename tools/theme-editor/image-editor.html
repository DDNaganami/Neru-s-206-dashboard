2 · 尺寸与配色

与主题里的 bg_color 一致：图片透明度会按这个底色合成
叠一层仪表弧，看遮挡关系
这里的颜色就是**主题里的那三条弧**：改完点「导出 theme.json」， 用 esptool 刷进 theme 分区就生效（固件不用重编译）。 本页只写弧与底色；五官、开机时长、数字读数那些字段缺失时固件用默认值 —— 要调它们请用主题编辑器（两页共用同一份配色，不会互相覆盖）。
注意：配色属于 theme 分区，图片属于 image 分区，是两次刷写。

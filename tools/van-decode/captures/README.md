# VAN 帧抓包（板子侧串口 dump）

这里放的是**主板固件自己打出来的**真实 VAN 帧，格式与 `lib/dashcore/van_replay.h`
接受的**回放格式逐字同形**：

```
VAN <IDEN> <字节...>   # cmd=<n> ack=<n>
```

## 与 `../sample-*.csv` 的区别（别混）

| | 本目录的 `.txt` | `../sample-*.csv` |
|---|---|---|
| 来源 | 主板固件解出来的**帧**（已过 CRC 校验） | 逻辑分析仪导出的**原始边沿** |
| 内容 | IDEN + 载荷字节 | 电平时间序列 |
| 用途 | **回放**（贴进串口即可复现）、对字段做统计 | 验**位层**（槽时间/4B5B/CRC 算法） |

两者互补：`.csv` 回答"线上长什么样"，`.txt` 回答"总线上有哪些帧、字段取值如何"。

## 怎么用

**回放**（把某一族贴进设备串口，或喂给宿主机测试）：

```powershell
python tools/van-decode/decode_frames.py captures/van-2026-09-28-idle-90s.txt   # 不对，见下
```

★ `decode_frames.py` 吃的是**边沿 CSV**，不吃本目录的 `.txt`。
要按 IDEN 统计/看字段，用现成的抓取脚本（见 `ACCEPTANCE.md` 2026-09-28 节）
或直接 `Select-String` / `grep`：

```powershell
# 某族的所有帧
Select-String -Path captures/*.txt -Pattern '^VAN 8A4'
```

**回放到板子**：把行贴进串口即可，`van_replay` 认这个格式
（`lib/dashcore/van_replay.h` 的文件头有说明）。

## 文件

| 文件 | 时长 | 帧数 | IDEN | 车况 |
|---|---|---|---|---|
| `van-2026-09-28-idle-90s.txt` | 90 s | 1501 | 11 | 通电、怠速附近 |
| `van-2026-09-28-idle-75s.txt` | 75 s | 1078 | 10 | 同上 |

**各 IDEN 的实测速率**（90 s 那份）：

| IDEN | 帧/s | 说明 |
|---|---|---|
| `0x824` | 5.2 | 转速/车速（**车速 = `data[2]` × 2.56 km/h**） |
| `0x464` | 5.0 | 空调状态 |
| `0x4DC` | 1.6 | 空调压力 / 蒸发器温度 |
| `0x664` | 1.1 | 仪表报警位图 |
| `0x4FC` | 1.0 | 灯位 / 门 / 油量 / （机油温度=空） |
| `0x9C4` | 0.9 | 遥控灯杆 |
| `0x5E4` | 0.9 | EMF 状态（超速/行程复位） |
| `0x524` | 0.5 | 多功能显示屏消息位图 |
| `0x8A4` | 0.4 | **水温 + 外界温度** |
| `0xE24` | 0.03 | **VIN 明文 17 字节** |
| `0x984` | 稀有 | 本趟只出现 1 次，未解 |

## ★ 这两份的独特价值

1. **`0xE24` 有 3 帧、且 `ack` 两种取值都有**（`ack=1` 与 `ack=0`）——
   仓库里另外两份样本只有 1 帧或无。**ACL/FCS 的处理可以拿它验。**
2. `0x8A4` 有 37 帧（0.4/s），水温/外界温度**跨较长时间窗**的样本
   —— 比 3 帧的切片更能看出慢变量的漂移。
3. 同时抓到了 `0x984`（罕见表）。

★ 注意这些速率是**整车静止/通电**状态下的。行驶时 `0x824` 会接近 80 Hz
（见 `ACCEPTANCE.md` 的 5 分钟行驶抓包）。

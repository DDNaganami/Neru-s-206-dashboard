无线刷写固件WiFi OTA

前提：这块开发板刷的是带 OTA 的档（esp32s3-rgb-slave-ota / esp32s3-rgb-master-ota，一次性 USB 刷），并且已经进了 OTA 模式 （串口敲 u，板子会起热点）。


        
★ 上传期间不要断电。旧固件在另一个槽里，所以传失败也不会变砖；
          10 分钟没人上传，板子自己退回正常固件。

      


      

        
怎么做（一页说明）

        
1. 串口敲 u → 板子重启进 OTA 模式（屏会黑，这是故意的）。

           2. 电脑 WiFi 切到 206dash-SLAVE / 206dash-MASTER。

           3. 回本页 → 选固件 → 「开始上传」→ 二三十秒。

           4. 板子自动重启成新版；把 WiFi 切回来即可。

        
不用本应用也行：连上热点后浏览器开 http://192.168.4.1/，
          板子自己有一个上传页（手机最方便）。

        
★ 上传用的是浏览器直连开发板 —— 如果浏览器拦了（跨域/网络），
          把板子自带的那页当备份路径。
